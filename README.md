# cat-fact-note
 Catfact Notes App
A simple MERN stack (MongoDB, Express, React, Node.js) note-taking app that assigns a random cat fact to each note created.

✨ Features
Create notes with title and content.

Each note is tagged with a random cat fact.

View all notes.

Search notes by title, content, or cat fact.

Delete notes.

Minimal but responsive UI.

🛠 Tech Stack
Frontend: React, Axios

Backend: Node.js, Express.js, MongoDB, Mongoose

Other: CORS, Axios for external API
